# Implementation Plan: MVP Prototype Dashboard

**Branch**: `003-mvp-dashboard` | **Date**: 2026-10-22 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/003-mvp-dashboard/spec.md`. Built autonomously while the researcher was away (they asked for decisions to be made and documented).

## Summary

A self-contained prototype in `mvp/` turns feature 001's provisional insider events into a six-page dashboard.

**Steps**: `uv run python -m mvp build` runs these in order:
1. Pick the pilot (2006–2011) and recent (July–September 2026) events, and resolve today's tickers.
2. Extract Form 4 purchases and sales from the 83 archives, to build company profiles and features.
3. Download and cache Yahoo prices for companies still listed, plus SPY and IWM.
4. Compute T+1-open abnormal-return paths, floors and costs, **for pilot events only**.
5. Summarise the event study, with month-block bootstrap bands.
6. Train and test logistic and LightGBM models against a market-only baseline, on 2006–2010 → 2011.
7. Score the recent events.
8. Render a static site with Jinja2.

**Serving**: `uv run python -m mvp serve` serves the site at `http://127.0.0.1:8765` (port 8000 was taken by another app on this machine). `uv run python -m mvp check` runs the constitution guards.

**Sharing**: the same site is published as a private claude.ai Artifact, giving a shareable URL.

## Technical Context

**Language/Version**: Python 3.14, uv

**Primary Dependencies**: new dependency group `mvp`: fastapi, uvicorn, jinja2, yfinance, scikit-learn, lightgbm (all in plan §8.3). Charts use Apache ECharts 5.6.0, vendored locally and loaded from cdnjs in the Artifact build.

**Storage**: `data/mvp/` (git-ignored):
- `raw/yahoo/*.parquet` plus `raw/manifest.jsonl`;
- `work/*.parquet` for intermediate tables;
- `site/` for the local build;
- `artifact/` for the publish build.

**Testing**: pytest in `mvp/tests/`, covering the guards, the return arithmetic, ticker choice and bootstrap determinism.

**Target Platform**: local browser via WSL2, and a claude.ai Artifact

**Project Type**: data pipeline plus a static-site dashboard (pre-rendered with Jinja2 and served by FastAPI)

**Performance Goals**:
- A cached rebuild in under 5 minutes; the first build in under 60.
- Pages are static, so they load in under 2 seconds.

**Constraints**:
- Outcomes only for signal dates ≤ 2011-12-31.
- `src/sentinel` never imports `mvp`.
- The pilot label appears on every return, model and score page.
- No raw Yahoo prices are shown.
- No Tiingo.

**Scale/Scope**:
- About 2,555 listed pilot events (about 1,008 companies), of which about 2,000 are priced.
- 244 recent events.
- About 6,700 companies with events in the lookup.

## Key Decisions (made autonomously; see research.md)

| # | Decision | Why |
|---|---|---|
| M1 | **Static site generated by Jinja2**, served locally by FastAPI's static files, and published unchanged as an Artifact | One build gives both the "active URL" the researcher asked for and a local demo that works offline. It uses the same templating as the future product (plan §8.3) |
| M2 | **Company lookup covers every company with at least one provisional event** (about 6,700), using quarterly buy/sell totals plus the last 25 transactions, in JSON split into 16 files, with search in the browser | "Any ticker" across about 12,000 issuers would not fit in an Artifact. Event companies are the ones the product is about |
| M3 | **The price widget (TradingView) appears only in the local build.** The Artifact links out instead | Artifacts may load scripts only from approved CDNs |
| M4 | **Recent events are scored by the selected model refitted on all pilot events (2006–2011).** The 2011 test metrics come from the 2006–2010 fit | Uses all the available pilot data for live scores. The test metrics stay honest |
| M5 | **Model selected by 2011 log loss** (spec FR-014). There is no tuning grid; fixed settings live in `mvp/params.yaml` | A prototype. Tuning comes in the full study |
| M6 | **Disclaimers on every page**: "Course prototype · not investment advice · independent of the SEC" | The pages show real company names and model scores, and may be shared |
| M7 | **Dependencies go in a uv dependency group `mvp`**, installed by default | Keeps the MVP's dependencies declaratively separate from the core |
| M8 | **Gates G8 (price check) and G7 (funds and blank-check companies, including issuers with no SIC code) added during the build** | Found by reviewing the first build; see run-notes.md M4–M5 |

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

| Principle | Compliance | Status |
|---|---|---|
| I. Point-in-Time | Features use only data up to the session at T. Entry is the T+1 open | Pass |
| II. Survivorship | Exempt only under the Prototype Exception: survivors-only is allowed with the mandatory label. Coverage is shown by group | Pass (exception) |
| III. Pre-registration | Outcomes only for pilot events before 2012. The returns builder raises on later dates, and a test checks the stored tables. Recent events are scored only | Pass (exception) |
| IV. Honest statistics | Gross and net shown; month-block bootstrap bands; a market-only baseline; nulls shown as they are | Pass |
| V. Reproducibility | Yahoo responses cached with a manifest; fixed seeds; a deterministic build | Pass |
| VI. Lawful use | Yahoo for personal use, with only derived results shown; no Tiingo; a licensed widget for charts; disclaimers | Pass |
| VII. Simplicity | Plan-stack libraries only; a static site; a contained folder | Pass |
| Prototype Exception | Code in `mvp/`, data in `data/mvp/`; containment and label guards; recorded as D44 | Pass |

## Project Structure

```text
mvp/
├── __init__.py, __main__.py      # CLI: build | serve | check
├── params.yaml                   # MVP-only settings (pilot dates, model settings, label text)
├── config.py                     # paths (data/mvp), params, label, guard helpers
├── pipeline/
│   ├── universe.py               # pilot/recent events, companies, ticker choice
│   ├── insider.py                # P/S Form 4 lines + owners from the 83 archives
│   ├── prices.py                 # yfinance batches, cache + manifest, split-unadjusting
│   ├── returns.py                # floors, cost, paths, BHARs (raises on ≥ 2012)
│   ├── study.py                  # event-study tables + bootstrap bands
│   ├── features.py               # Form 4 + price features as of T
│   ├── model.py                  # train/test/score, calibration, importance
│   └── companies.py              # company profiles + search index (split JSON)
├── site/
│   ├── render.py                 # Jinja2 → data/mvp/site and data/mvp/artifact
│   ├── templates/                # base + 6 pages + macros
│   └── static/                   # style.css, app.js, vendor/echarts.min.js
├── DEMO.md                       # 5-minute class walkthrough
└── tests/                        # guards + unit tests
```
